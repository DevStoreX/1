# Ejemplos de diseños paramétricos

Estos archivos muestran el estilo que usa el agente de Forja: todas las medidas importantes
son **parámetros Customizer** (se convierten en controles deslizantes en la app, en OpenSCAD
y en el Customizer de Thingiverse/MakerWorld).

| Archivo | Qué es | Soportes |
|---|---|---|
| `soporte-celular.scad` | Soporte de escritorio con ángulo, grosor y hueco para el cable ajustables | No |
| `organizador-cables.scad` | Clip bajo la mesa para N cables con abertura a presión | No |
| `llavero.scad` | Llavero con nombre en relieve (ideal con niños) | No |

Para abrirlos en Forja: pestaña **Crear** → pide al agente «abre el ejemplo del soporte», o
pega el código en el editor de un modelo. También puedes usarlos con OpenSCAD de escritorio.
