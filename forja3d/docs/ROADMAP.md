# Hoja de ruta

## v0.1 — Base funcional (esta versión)
- [x] Agente conversacional con Claude y modelos locales
- [x] CAD paramétrico OpenSCAD + Manifold (WebAssembly) con controles deslizantes
- [x] Análisis de imprimibilidad, estimación y precio justo
- [x] Figuras orgánicas con TRELLIS/Hunyuan3D a precio de costo
- [x] Bambu Lab, PrusaLink, Moonraker, OctoPrint
- [x] Cámara con IA y pausa automática
- [x] Servidor MCP (HTTP y stdio)
- [x] Español/inglés, modo niños, móvil, modo oscuro, Docker

## v0.2 — Mejor impresión
- [ ] Compilar OpenSCAD en el navegador (vista previa instantánea, cero servidor)
- [ ] Exportar 3MF con varias piezas y ajustes por objeto
- [ ] Laminado integrado con perfiles de OrcaSlicer (enviar directo a Bambu sin pasos manuales)
- [ ] Orientación automática (menos soportes, más resistencia)
- [ ] Análisis de grosor de pared y de puentes largos
- [ ] Reparación de mallas generadas por IA (remallado por vóxeles)
- [ ] Probar los conectores con más impresoras reales (¡ayuda bienvenida!)

## v0.3 — Inventos y comunidad
- [ ] Biblioteca de mecanismos paramétricos (bisagras print-in-place, engranajes, clips, roscas, resortes)
- [ ] "Explícame este invento": modo guiado que descompone un objeto en principios físicos
- [ ] Biblioteca comunitaria con licencias claras y reparto justo para quien diseña
- [ ] Modo aula: proyectos para docentes, retos por edad y galería de la clase
- [ ] Voz: hablarle al agente (ideal para niños pequeños)
- [ ] App instalable (PWA) y aplicación de escritorio de un clic
